# 大沼 優之介のポートフォリオ

HTML / CSS / JavaScript で作成した個人ポートフォリオサイトです。

## このサイトで伝えたいこと
- 自己紹介
- スキル
- 作品一覧
- 学びの経歴
- 連絡先

## ローカルで見る方法
ブラウザで `index.html` を直接開くか、次のコマンドでローカルサーバーを立ち上げてください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いてください。

## GitHub Pages で公開する方法
1. GitHub リポジトリに push する
2. GitHub の設定メニューから **Settings** → **Pages** を開く
3. **Deploy from a branch** を選択
4. `main` ブランチと `root` を選択して保存
5. 公開URLが表示される
